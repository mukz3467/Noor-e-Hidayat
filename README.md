# Noor-e-Hidayat Android starter v0.7.0

Dark emerald and gold Islamic video app prototype. See app/src/main/assets/index.html for the app UI and .github/workflows/android-apk.yml for the debug APK workflow.

Build requirements: Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compile SDK 35, min SDK 23. A debug APK has not yet been built or device-tested. YouTube availability depends on publisher, region and embedding permissions. AdMob and full UI translations are not implemented.
